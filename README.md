# mend — one patch tool for every AI edit format

A command-line tool that applies AI-written edits in four formats (unified diffs with wrong line numbers, SEARCH/REPLACE blocks, V4A patches and JSON tool calls) to a tree of files, to the specification in the kit. It finds the lines an edit names even when the model drifted their whitespace or indentation, and changes every file or none.

Run `node main.ts [options] [PATCH]` (Node 22, standard library only). See the competition page: https://make.fun/bounty/hidden-spec-cli-01-run-20261122
